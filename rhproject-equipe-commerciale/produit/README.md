## Règles d'usage pour les agents

1. **Source unique** : toute affirmation sur le produit doit se retrouver dans ces fichiers. Sinon répondre « je vérifie » et remonter la question au Directeur.
2. **Trois niveaux de certitude** : *lu dans le code* (fiable), *(à vérifier à l'écran)* (probable), *point d'attention* (incohérence connue).
3. **Mise à jour** : à chaque nouvelle version de l'application (le numéro de build figure en première ligne du fichier), le Veilleur compare les nouveautés, met à jour ces fichiers et en informe le Directeur ; la fondatrice valide les changements de prix ou de promesses.
4. **Aucune donnée technique sensible** (clés, identifiants de paiement, adresses d'infrastructure) ne doit être recopiée dans ces documents ni dans les messages aux prospects.
5. **Ne jamais déduire une fonction à partir d'un nom de menu** : la lire dans ces manuels.
